# Ali Alalwia — Electrical Engineering portfolio

Static GitHub Pages website with fifteen detailed project pages and two supporting embedded-system projects. No build tools required.

## Publish
1. Create a public repository named `h3xadecima1.github.io` on GitHub.
2. Upload every file in this folder (not the enclosing folder) to the repository root and commit to `main`.
3. Open Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Check https://h3xadecima1.github.io after GitHub finishes deployment.

## Sources and review
All project images are linked directly to verified paths in the six original public repositories. They are not copied locally and need internet access. Project source code and PDFs are linked to their original GitHub files. Binary PDF contents and photographs could not be independently inspected; descriptions use readable project README, Arduino sketches, KiCad files and SPICE netlists. The ALU, DAC and DC-DC converter have clearly labeled conceptual illustrations rather than fabricated photos; original reports and design files are linked. FPGA labs include original demonstration GIFs. Review project image contents, PDF content, team contribution wording and results before publishing. No original repositories were changed. No external analytics or tracking scripts are included; Google Fonts is optional and system fonts are the fallback.

The autonomous delivery drone page presents a research proposal, not a completed prototype. The original uploaded review and research outline presentation are provided as PDF exports in `research/`.


The SDR team project includes the original uploaded paper, presentation and extracted project images in `sdr/`.
