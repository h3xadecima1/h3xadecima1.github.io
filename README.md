# Ali Alalwia — Electrical Engineering portfolio

Static GitHub Pages website with seven detailed project pages and two supporting embedded-system projects. No build tools required.

## Publish
1. Create a public repository named `h3xadecima1.github.io` on GitHub.
2. Upload every file in this folder (not the enclosing folder) to the repository root and commit to `main`.
3. Open Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Check https://h3xadecima1.github.io after GitHub finishes deployment.

## Sources and review
All project images are linked directly to verified paths in the six original public repositories. They are not copied locally and need internet access. Project source code and PDFs are linked to their original GitHub files. Binary PDF contents and photographs could not be independently inspected; descriptions use readable project README, Arduino sketches, KiCad files and SPICE netlists. The ALU has a clearly labeled conceptual illustration rather than a fabricated photo. Review project image contents, PDF content, team contribution wording and results before publishing. No original repositories were changed. No external analytics or tracking scripts are included; Google Fonts is optional and system fonts are the fallback.
