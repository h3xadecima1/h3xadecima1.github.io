4-Bit FPGA Microprocessor

Microprogrammed Verilog processor with instruction sequencing, ROM, arithmetic datapath and UART debugging.

Project repository ↗

Project overview

A modular four-bit processor on the Intel DE10-Lite FPGA combines A/B accumulators, an arithmetic unit, input/output registers, ROM, program counter and FSM-based microinstruction control. A manually stepped clock enables instruction-by-instruction observation.

Engineering implementation

  • Integrated the datapath and control modules on a shared internal bus.
  • Implemented instruction fetch, decode and execute sequencing and ADD/SUB operations.
  • Connected seven-segment displays and UART debug output for monitoring registers, bus values and carry.
  • Used debounced reset and step-clock logic.

Results & scope

The project report records successful accumulator, ALU, FSM and UART verification. Board and PuTTY demonstrations are included in the repository; these reported results have not been independently rerun.
