Multi-Mode Mobile Robot

Arduino-based four-motor robot with switch-selectable line tracking and proximity-based behaviors.

Arduino C++DC motorsUltrasonicServo
Project repository ↗

Project overview

The final Arduino sketch uses NewPing, Servo and AFMotor libraries. It reads line sensors and ultrasonic distance, controls four DC motors, and uses a servo to scan left and right during obstacle avoidance.

Engineering implementation

  • Implemented switch-based operating modes and motor direction/speed routines.
  • Used ultrasonic distance and directional sensor inputs for navigation decisions.
  • Added servo scanning and gradual motor speed changes.
