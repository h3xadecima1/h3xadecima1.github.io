5-Bit Digital-to-Analog Converter

Project repository ↗

Project overview

The DAC library includes schematic, icon and physical layout cells for a five-bit converter and resistor-divider subcircuit. The SPICE deck connects five divider stages using 10 kΩ resistors, with a 10 pF output load in the transient testbench.

Engineering implementation

  • Designed the resistor-divider building block and five-bit DAC hierarchy.
  • Created schematic and physical layout views in Electric VLSI.
  • Prepared a transient simulation deck with a pulsed input and capacitive output load.

Results & scope

The original library and SPICE decks document the design and simulation setup. Full-code transfer linearity, settling time and measured hardware accuracy have not been independently verified.
