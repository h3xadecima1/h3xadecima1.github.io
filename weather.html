Weather Balloon Sensor PCB

Environmental sensing board built around an Arduino Nano footprint and dedicated sensor interfaces.

Arduino NanoKiCadI²CSensors
Project repository ↗

Project overview

The KiCad design includes temperature, humidity and pressure sensing, an I²C interface, OpenLog connection, six LED signals and 3.3 V / 5 V power nets. Components include the DHT11 humidity sensor and a 40PC015G pressure sensor.

Engineering implementation

  • Created a two-layer board with 110 routed copper segments.
  • Integrated environmental sensor and logging connections.
  • Exported Gerbers, schematic, BOM and final block diagram.

Results & scope

The final board and fabrication documentation are present. Balloon flight, data collection and measured sensor accuracy have not been verified.
