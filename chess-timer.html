FPGA Digital Chess Timer

Two-player countdown timer using a Moore finite state machine, counters and display control.

VerilogFSMCountersFPGA
Project repository ↗

Project overview

A Moore FSM controls two independent countdown counters. Its four states are IDLE, PLAYER1, PLAYER2 and END, with mutually exclusive counter enable signals and game termination when a counter reaches zero.

Engineering implementation

  • Implemented state transitions for start, turn switching, expiry and reset.
  • Integrated countdown counters and seven-segment display control.
  • Documented state diagrams and five verification cases.

Results & scope

The report marks all five state-transition test cases as passed and describes successful simulation. An original board demonstration GIF is included.
