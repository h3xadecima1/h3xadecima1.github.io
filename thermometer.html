Arduino UNO Digital Thermometer Shield

Custom Arduino UNO shield combining digital temperature sensing, OLED readout and motion-aware display orientation.

Arduino UNODS18B20KiCadI²C / OneWire
Project repository ↗

Project overview

A digital thermometer implemented as a custom two-layer Arduino UNO shield. The firmware reads a DS18B20 temperature sensor over OneWire, displays measurements on an SSD1306 OLED and uses the MPU6050 accelerometer to rotate the display based on orientation.

Engineering implementation

  • Designed a two-layer KiCad PCB with 160 routed copper segments and Arduino-compatible connectors.
  • Configured 11-bit temperature conversion and Celsius/Fahrenheit display with one decimal place.
  • Implemented five button-controlled functions: display power, button lock, unit selection, simulated calibration and LED control.
  • Used I²C for OLED and motion sensor communication, OneWire for temperature sensing and serial output for diagnostics.
  • Prepared fabrication Gerbers, drill files, schematic, 3D model and interactive bill of materials.

Results & scope

PCB design and firmware are documented in the repository. The calibration function displays a fixed 22 °C for five seconds to simulate calibration; measured accuracy and physical test results are not independently verified.
