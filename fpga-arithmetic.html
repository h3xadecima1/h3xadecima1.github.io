Project overview

Five progressively more complex arithmetic designs target the DE10-Lite FPGA: an eight-bit accumulator, add/subtract accumulator, four-by-four array multiplier, eight-by-eight registered multiplier and four-by-four adder-tree multiplier.

Engineering implementation

  • Implemented accumulators, arithmetic mode selection and overflow indication.
  • Integrated binary-to-BCD conversion and seven-segment display interfaces.
  • Compared array and parallel adder-tree structures, and used registers around the eight-bit multiplier.

Results & scope

The report includes block diagrams and board demonstration GIFs for each part. No independently verified timing or resource-utilization measurements are claimed.
