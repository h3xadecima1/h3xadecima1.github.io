6502 FPGA CPU Core

Microcoded 8-bit CPU architecture implemented in Verilog for the DE10-Lite FPGA platform.

VerilogFPGAPythonSimulation
Project repository ↗

Project overview

A modular MOS 6502 soft-core with an 8-bit data bus, 16-bit address bus, register file, ALU, addressing unit, stack, interrupt logic and ROM-driven control. Python scripts generate 40-bit microinstructions.

Engineering implementation

  • Developed the CPU datapath and microcoded sequencing.
  • Integrated RAM/ROM interfaces and WozMon firmware into the simulation environment.
  • Used testbenches and waveform analysis to examine instruction sequencing, flags and memory operations.

Results & scope

The project README reports successful WozMon execution and waveform verification in simulation. UART/VGA and external storage integration remained unresolved; full standalone FPGA computer operation is not claimed.
