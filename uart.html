FPGA UART Word Detection

Serial communication and finite state word detection driving a timed seven-segment display.

VerilogUARTFSMMAX10
Project repository ↗

Project overview

The DE10-Lite design receives ASCII characters over UART at 115200 baud using a 50 MHz system clock. A finite state machine detects the word hello and blinks HELLO on five seven-segment displays for three seconds.

Engineering implementation

  • Integrated asynchronous receiver and transmitter modules for serial input and echo.
  • Implemented sequential ASCII word matching and timed display control.
  • Displayed received bytes on board LEDs and documented reset behavior.
